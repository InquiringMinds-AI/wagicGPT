# deck162 - skill proposals (wave 51)

S-1. **WHEN THE ENGINE STARTS PRINTING A COUNT THE GUIDE USED TO DERIVE, THE GUIDE'S EXCEPTIONS
MOVE ONTO THE SAME ROW OR THEY ARE LOST.** Lane F put `converters on your battlefield: K` on every
engine row; the guide's brake said "count the names on your battlefield line" and its one
exemption (the first Howling Mine) sat in cast-order entry 5. The pilot read the new "0" as the
brake in four windows with no Mine out (`162 vs130` s5/s6/s9/s10) and read past it once with a Mine
out (`162 vs146` s6). A printed count is the strongest key on the screen; a rule keyed to it must
carry its exceptions in the same sentence ("K of 0 - the FIRST Mine is cast at 0 anyway"), because
the number will be read before any other paragraph. Corollary for #149: an engine count that
includes a converter the guide qualifies (Caress at hand < 7) is re-qualified beside the string,
never by a second count.

S-2. **THE #143 METRIC HAS AN ENGINE-SIDE HALF: PUT-vs-EXECUTED.** `162 vs146` s17: reply `PUT: 3
(Forced Fruition)`, executed Liliana's Caress (row 2). The PLAN-vs-PUT comparison scores the pilot
and passes this window; the divergence is between the emitted list and `chosen_text`. Rule: at
every list-answer ask the reviewer's first check is reply-numbers == executed-names, and a
mismatch routes to the engine list before any guide sentence is touched. (Also filed under
deck146 S-3; one rule.)

S-3. **A 2-4 ON A DECK WHOSE RULE FRACTIONS HELD IS NOT A GUIDE VERDICT, AND THE SEAT FILE SAYS
WHICH LOSS HAD A WINDOW.** Three of the four losses here had no window in the log with a better
legal answer (a 21-creature Alarm board on turn 11; a four-land turn-8 first spell; Starstorm +
Rorix). The one with a window is the one edited. The new-baseline rule (hands are real) already
says this for win rates; extend it to the rotation call - a deck stays on the roster for its
open guide lanes, not its record, and a seat file lists per loss "window / no window".
