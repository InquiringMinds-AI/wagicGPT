# deck162 — proposals for the strategy-writing skill (wave-45 evidence only)

## S-I. A RESTORATION IS AN EDIT AND IT DISCHARGED CLEANLY — RECORD THE SHAPE
Wave 43 cut deck162's ATTACKING section to stops; wave 44 falsified that cut twice and restored the
affirmative rung plus the collapsed-tag gate. Wave 45's measurement: attack windows with a send
**12 of 12** (was 2 of 6), all-"(you kill it, your attacker lives)" tags **sent 2/2**, and the deck
went 5-1. Amendments #35 and #36 were both written off this deck and both are now confirmed by the
repair, not only by the damage.
PROPOSAL: keep #35/#36 as written and add a note that the repair validated in one wave with a
countable metric (send rate per attack window). That metric is the cheapest available test for
"prohibition-only section" anywhere in the corpus and should be in the Definition of Done for every
guide with a combat section: **report sends-per-attack-window and blocks-per-block-window as raw
counts, per deck, every wave.** A deck that answers "none" most of the time is a defect signal
before anyone reads a single reply.

## S-J. A GATE THAT SURVIVES A FAVOURABLE VIOLATION MUST BE RECORDED AS SURVIVING, NOT AS VINDICATED OR AS WRONG
deck162 broke its own collapsed-tag gate at vs123 seq 23 (the tag printed "GANG BLOCK: their 2
biggest together deal 5, enough to kill this attacker"), the opponent chose a lone block, the
attacker lived, the deck won the game. It also broke its engine brake three times in the exact shape
the guide names, and won that game too. Both are n=1 favourable samples on rules whose whole value
is in the tail.
PROPOSAL: give the seat files an explicit verdict token for this, distinct from PASS/FAIL:
**VIOLATED-UNPUNISHED.** Amendment #45 already forbids closing a lane on a low-power sample and #47
requires grading by odds rather than outcome, but reviewers still need somewhere to put "the rule
was broken and nothing happened" so it does not silently accumulate as evidence for loosening. The
odds argument belongs in the same cell as the outcome.

## S-K. THE SAME TEACH IN THREE GUIDES CAN FAIL THROUGH THREE DIFFERENT DOORS — DIAGNOSE PER GUIDE, NOT PER RULE
The per-creature "(your attacker dies, their blocker lives)" stop went 0 for 7 across deck146,
deck152 and deck162 this corpus. The tempting conclusion is that the rule is unteachable. The replies
say otherwise: deck146 lost it to a competing EXCEPTION on the same rendered line, deck152 lost it to
a BENEFIT printed inside the parenthesis, deck162 lost it to LIFE PRESSURE with no counter-argument
written down. Three fixes, three guides, one rule.
PROPOSAL: when a cross-guide teach fails at every seat, the skill's instruction should be to read
the three replies for three different override arguments BEFORE proposing a single reworded rule —
and to write the fix into each guide in the vocabulary of the argument that beat it there
(amendment #28). A single canonical rewording would have fixed at most one of these three.

## S-L. A GUIDE THAT NEVER RECEIVED A SIBLING'S FIX IS A STANDING DEFECT, NOT A GAP TO NOTICE LATER
Amendment #25's survival gate shipped to deck146 and deck152 in wave 44 off deck152's death, and not
to deck162, which has the same one-blocker-many-attackers exposure. Its first live LETHAL window in
wave 45 cost it its only loss's decisive decision.
PROPOSAL: when an amendment is written off one seat's evidence, the wave's synthesis step should
enumerate which other guides in the pool have the same decision surface and either apply it or
record why not, in that wave — the same discipline #32 asks for render-string rules, applied to
procedural gates.
