# deck162 -> strategy-writing skill proposals (wave 56)

## S8 (STRONG) - a brake's success is measured in WINDOW COUNT, and the skill should say so.
EVIDENCE. deck162's HOLD/declined-note economy: renders 174 -> 65, windows at declined-note N>=2
**65 -> 0**, `hold_windows_skipped` on gameends 6 -> 1 of 6 seats. The deck's record is 5-1 in both
corpora, so the record says nothing; the window count says the wave-55 edit worked and the lane
can close. This is the same instrument the wave-55 seat used for 162-A (10 -> 3) and it is the only
one of my three decks' measurements that survived a 3-3 -> 5-1 and a 5-1 -> 3-3 swing untouched.
PROPOSE: state in the skill that under the new-baseline rule the admissible evidence for a guide
edit is a WINDOW COUNT on the edit's own literal, never a win rate, and that a reviewer who cannot
produce one has not adjudicated the edit.

## S9 (MED) - carve-outs beat tightenings when every hit of a prediction is a correct play.
EVIDENCE. deck162's P6 fired 3 times this corpus and 3 times last; all six were defensible and two
of this corpus's three were a duplicate legend the render already tagged
(`[legendary: you already control one ...]`). The rule was not wrong about the game - its KEY was
picking up windows the render had already settled.
PROPOSE (converges with deck146's S4): when a rule's key overlaps an annotation the render now
carries, the edit is to name the annotation as an exemption, not to restate the rule harder. The
render is the cheaper enforcer and it is already on the screen.

## S10 (MED) - a guide that names a card class must name what does NOT belong to it.
EVIDENCE. deck162's brake releases on "a converter". Forced Fruition is the deck's biggest FEEDER
and reads like an engine piece, and at `162v125` s15 the pilot treated it as if it discharged the
brake. The guide had listed the converters; it had never said Forced Fruition is not one.
PROPOSE: for any guide rule keyed on membership of a card class, the skill requires ONE named
NEAR-MISS - the card in this deck that most looks like a member and is not. Positive lists are read
as open; a named exclusion closes them.
