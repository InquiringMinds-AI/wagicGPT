# deck125 - proposals for the strategy-writing skill (wave 50)

S1 - A FIXED-NUMBER GATE THAT FAILS FOR SEVEN CORPORA WHILE ITS BREAKS STOP COSTING GAMES IS
RE-DERIVED FROM ITS PURPOSE, NOT RESTATED. deck125's Staff gate ("leaves 5 or more") failed 3/6,
then 2/5 casts across two corpora; in this one both breaks were harmless BY THE GATE'S OWN
PURPOSE (`vs162` seq 20: the only counter in hand was an Essence Scatter against a deck that cast
no creature; `vs123` seq 29: leaves 2 with a 2-mana Scatter in hand). The "5" was the Gavel's cost
generalised to every counter. Re-derived rule: the gate's number is the printed cost of the
cheapest counter in hand that can hit what the opponent casts (W22). Proposed skill rule: when a
numeric gate's breaks stop correlating with losses, check whether the number was one case's
constant; if so, write the gate as the quantity it stands for (a cost read off the hand line),
and keep the old losses as the test that the new rule still forbids them. Extends #102 (what to
do at exhaustion besides routing to the engine) and #118.

S2 - A SENTENCE THAT IS TRUE ONLY WHILE A STATE HOLDS NAMES THE STATE. "Your battlefield has no
creatures, so a board wipe only ever costs the opponent" was true for 40+ windows and false the
one turn an Emrakul was out; the seat cast the Verdict off a row that printed `1 of yours`
(`vs126` seq 44). The render carried the fact; the guide's unconditional sentence outranked it in
the executor's reading. Proposed rule: every "always"/"only ever" sentence about the seat's own
board is audited for the deck's own exceptions (a finisher creature, a token maker), and the
exception is written into the sentence, keyed to the row token that changes (`1 of yours`).

S3 - A RULE RESTATED IN THE MODEL'S OWN PLAN LINE AND BROKEN IN THE SAME REPLY IS EXHAUSTED AT
THAT SEAT (confirmation of #102/#132). `vs126` seq 42: plan "cast it unless Sanguine
Bond/Exquisite Blood/Tribute to Hunger are present" + `CHOICE: 1 (Cast Emrakul)` with Exquisite
Blood on the line. The wave-50 edit re-keys the rule to the printed `{effect:}` text (W20) and
routes the rest to a render proposal (G1); no third restatement. Recorded as an instance.

S4 - A NEW ASK KIND (cleanup `discard`) GETS A SECTION THE FIRST CORPUS IT APPEARS, MIRRORING THE
BOTTOMING ORDER. Nine asks with no text; two sends against the deck's logic (a Cancel over a
Lightmine at 44 life). Proposed: the skill's checklist for a render ship that adds a decision
kind includes "every guide names the order for it before the next corpus" (W25; deck126 F18 is
the costlier instance - a Tribute discarded over a Lantern, then Bloodline Keeper #2 with no
answer).
