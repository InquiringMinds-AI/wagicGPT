# deck162 - proposals for the strategy-writing skill (wave 50)

S-1. **A BRAKE KEYED TO A COUNT MUST COUNT EVERY CONVERTER OF THE RESOURCE IT BRAKES - AND THE
MISSING CONVERTER IS FOUND BY READING THE WIN'S NARRATION, NOT THE LOSS'S.** RULE 2 counted
punishers (draw -> damage) and braked draw engines at zero; Liliana's Caress converts DISCARDS,
which the same engines cause once the hand is full, and the seat's `vs123` win ran 14 damage
through Caress before any punisher landed (s9/s11/s16 events). Four corpora scored those engine
casts as "violated-unpunished" (#64/#118) when three of the five were the deck's actual kill.
Proposed rule, a #106 companion: before a violated-unpunished verdict is carried to #118's ceiling,
read the winning game's `events` for the damage source - if the "violation" is what dealt the
damage, the rule's count is missing a converter and the fix is a fact, not a restatement or a
loosening.

S-2. **THE LETHAL CHECK ENUMERATES ONE-SHOT DRAW SOURCES THE PILOT CONTROLS, NOT ONLY THE
PER-TURN ONES.** The guide's LETHAL CHECK multiplied Mines and Boxes by P but never priced Ob
Nixilis's -2 ("its controller draws two cards" = 2 x P immediately); the seat passed a lethal -2
twice at their 3 life (`162 vs126` s23/s24). #112 put the lethal count first in the turn for a
creature-mana deck; this is the same audit for a punisher deck: list every card whose text makes
the OPPONENT draw (Ob Nixilis -2, Peer into the Abyss, Forced Fruition on their cast) and give
each a line in the lethal arithmetic with its timing window.

S-3. **SUPPORTING INSTANCE (#131): a single-verdict gap is closed the wave it is named.** The
wave-49 boundary pass named deck162's missing all-lands sentence; added this wave (162-F) with the
twelve-hand check re-run. No change to the skill.
