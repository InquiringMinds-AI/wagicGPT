# deck126 - proposals for the strategy-writing skill (wave 50)

S1 - AN "EXACTLY ONE" ABSOLUTE IS AUDITED FOR THE CASE WHERE THE ONE IS HARMLESS. deck126's
Tribute-at-one rule ("cast at any life total, whatever that creature is") reached ceiling and then
spent the deck's only own-turn win trigger on a Shield Sphere (`vs162` seq 8); the window that
needed it (both halves out, two Fog Banks, 3 life, seq 23-24) had none. Proposed rule: when a
guide says "whatever it is" about a target class, construct the class's least harmful member
(here a [defender]) and ask whether the rule's purpose (removal) applies to it; if not, the
member is carved out with the printed tag that identifies it (F17). Sibling of deck125 S2 (the
"only ever costs the opponent" sentence).

S2 - A NEW ASK KIND GETS ITS ORDER BEFORE THE NEXT CORPUS, AND THE ORDER IS COPIED FROM THE
NEAREST EXISTING ONE. Lane W's cleanup `discard` ask arrived with no guide text at any seat;
deck126 discarded the third Tribute over a Lantern on turn 4 and died to the creature that Tribute
answers (`vs123` seq 7 -> -208). The bottoming order two sections down already said "Lantern or
Staff first". Proposed rule: a render ship that adds a decision kind is paired with a per-guide
order derived from the closest existing one (bottoming for discard), and the seat file's first
corpus on it records every send against that order (F18; deck125 W25).

S3 - "DO NOT GO OUTSIDE THIS LIST" MUST NAME THE LIST IT MEANS: THE MENU, NOT THE GUIDE'S
ENTRIES. Three replies named a hand card as a numbered CHOICE (`vs125` seq 14, `vs162` seq 16,
`vs130` seq 13) and were discarded as `stale_echo`; Rule 7's closing sentence was about the
entry list. Proposed rule: every guide carries one sentence tying the CHOICE to a printed row and
naming the commonest reason a hand card has no row (an unpayable pip), keyed to the mana line's
per-colour count (F19). The render half is seat-file HIGH #1 (a re-ask instead of a fallback).

S4 - THE ROW'S OWN STRING REPLACES THE HEADER AS THE KEY THE MOMENT THE ROW CARRIES THE FACT
(instance of #118). The edict row now names the victim and the gain; the guide's
header-keyed "of which 1 is a creature" was re-keyed to `<name> is sacrificed, you gain N`
(F16), which is shorter for the executor and is also the token the new carve-out (F17) hangs on.
Recorded as an instance, not a new amendment.
