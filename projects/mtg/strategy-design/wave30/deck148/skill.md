the FIRST pass for equipment/aura-lord decks. Both teaches fired on first guided exposure:
- attack floor: durdle-to-t11 is dead; the deck swung t4-every-turn (vs152, -> win) and t2-every-turn
  (vs122); late first-attacks were creature-starvation, not passivity.
- gear-the-lord-first: the one game where the lord (Armament Master) survived (vs152), the FIRST equip
  of the game went onto the lord itself, then the pumped team won. Textbook execution of the
  prescribed sequence.
Recommendation to synthesis: keep wave-29 Proposal 1 as-is; it is now VALIDATED, not just proposed.
NEW sub-observation worth a line: for a FRAGILE lord (a small unprotected body like AM, a 2/2), the
"gear it first" sequence is gated on the lord SURVIVING - in vs136 AM was cast then died bare before
gearing. This is not a guide-authoring fix (the guide cannot keep a dead lord alive) but it is a
signal that "gear-the-lord-first" and "the lord's own survivability" are a construction pair - flag
in the skill that when the lord is fragile the teach's realized value is variance-bound, and that is
a construction observation, not a guide-length problem.

to the roster owner, and (c) enter near-terminal rotation. Ceilinged is not "keep revising"; it is
"one validation corpus, then freeze + hand off." Recommend the skill state this exit explicitly so a
future ceilinged seat is not held for endless guide passes.
