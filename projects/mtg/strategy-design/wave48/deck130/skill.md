# deck130 - proposals for the strategy-writing skill (wave 48)

Only what this seat's evidence supports. Numbers in `seat-123-130.md`.

**S1. SUPPORTING INSTANCE FOR #71 (an absolute needs its survival carve-out as a numbered check
above it), with the measurement that makes it cheap to apply.** Rule #2 (a) - "never cast
Starstorm when YOURS names Rorix or Siege-Gang" - was written off a game where the sweep killed
the deck's own clock at 1 life. At 8 life against 17 printed power (vs152 seq 26) the same
absolute declined the only sweep that keeps the deck alive, and the Commander it protected
attacked into a 5/3 lifelink blocker the next turn and died anyway. The carve-out's input is a
SUM the pilot can take off one printed line (their creatures' P/T), which #72 allows; the seat
wrote it as "SURVIVAL FIRST, above (a) and (b)" with the sum named. The authoring step to add to
#71: for every absolute, name the printed quantity whose value would make obeying it fatal,
and put the comparison above it.

**S2. A RULE KEYED TO ONE FORM OF A RENDERED TAG MUST NAME THE OTHER FORMS THE EMITTER CAN
PRODUCE (extends #82 from absence to variants).** The keep-the-Commander-home rule read the
COLLAPSED blocker tag (`they have N untapped creatures ... GANG BLOCK`). On a three-creature
board the same tag is ENUMERATED (`[their untapped blockers: A (...); B (...); C (...)]`) and no
rung matched; the Commander was sent into three "your attacker dies" prices and died (vs152 seq
24). #82 says branch on the token's absence; the same tag has at least two PRESENT shapes
(enumerated / collapsed), and a rule that quotes one shape is silent on the other. Reviewer
check: for every tag a rule quotes, list the emitter's shapes for that tag (the carry names
them) and write the rule's input as the fact both shapes carry (here: the COUNT of blockers
named).

**S3. WHEN THE RENDER MARKS THE ANSWER, THE RULE IS "ANSWER THE MARK" AND THE DERIVATION
BECOMES THE FALLBACK (#49 applied to a decision procedure).** Lane Q's `[<- most kills at any
affordable X that costs you nothing]` sits on exactly the row STEP 1 + STEP 2 derive. The guide
still opened with the derivation, and the one miss this corpus (vs146 seq 47, X=6 over a marked
X=2) is the pilot stopping at STEP 1 and never reaching STEP 2. When an emitter marks the row a
multi-step rule computes, the rule's first line is the mark; the steps stay only for the case
where the mark is absent (and say so).

**S4. WATCH: THE ACTION-LESS PLAN.** "The game is lost ... passing is the only legal action"
was carried 48 windows and produced a self-targeted Hammer and a blank X=12 Starstorm. The guide
now says a PLAN names the next action (D48-7); the durable fix is the core prompt's (general-
suggestions R3). If it recurs at another seat with the guide line in place, it is an amendment
about what a PLAN may contain - "a plan is an action list; a verdict is not a plan".
