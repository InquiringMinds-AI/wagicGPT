# deck162 - proposals for the strategy-writing skill (wave 48)

S-1. **TWO CHAIN-STOPS AT DIFFERENT LOOKS IN ONE POOL ARE A CROSS-GUIDE CONTRADICTION, AND THE
SECOND-LOOK STOP COLLIDES WITH ITS OWN LAND BRANCH.** deck146 and deck152 stop the chain at
`(keeping 5)`; deck162 stops it at the SECOND look ("already taken 1 mulligan -> keep") while
also saying "ONE LAND: ship it". On a one-land six both sentences apply and neither names the
other (#97). Amendment 67 fixed the stop at `(keeping 5)` pool-wide; this guide's earlier
sentence survived the pass. Definition-of-Done: every mulligan section states exactly ONE stop
look, the same look as the rest of the pool, and every land-count branch says whether it applies
at the stop look. (Owner question Q2 pending; no text moved.)

S-2. **"VIOLATED-UNPUNISHED" HAS A CEILING: AT THE THIRD CORPUS, #102 APPLIES EVEN WHEN NO GAME
WAS LOST.** Amendment 64 gave the verdict a name so favourable violations would not accumulate
as loosening evidence. Rule 2's streak (3, 3, 6 breaks; 0 losses) shows the other failure: it
accumulates as NOTHING, and a rule that is broken 40% of the time it fires is not a rule the
pilot has. The #102 trigger ("third identical failure with the fact rendered") should read
"third corpus", not "third lost game": shrink, re-key to the printed count, plan-sentence check.

S-3. **AN EXCEPTION'S CONDITION IS QUOTED BACK WITHOUT ITS CONDITION.** "With NO punisher out,
cast Master of the Feast whenever the opponent's battlefield line shows a creature" was cited by
the pilot as "MotF is the exception: it is a body that defends against threats" on a board that
showed 0 creatures. The exception's NAME survived; its condition did not. Write the condition as
the printed count (`"of which N are creatures" with N of 1 or more`) and write the negative case
in the same sentence (`At "of which 0 are creatures" it waits`) - #98's both-polarities rule
applied to an exception clause.

S-4. **A "BIGGEST" TARGET RULE FOR REMOVAL NAMES THE ENGINE CLASS FIRST (#17 for targets).**
Ob Nixilis's -2 took a 1/1 token beside a Thraben Doomsayer; the maker made twenty more. Any
removal-target rule lists "creatures whose text makes creatures" ahead of size, by name and by
the text words the row prints ("create", "put a ... token").

S-5 (measurement). **A seat with 0 `blockers` records in six games has a whole section that
cannot be scored** (zero-power walls, the LETHAL gate, rung 3). Report `blockers` window counts
per seat alongside sends/blocks so a structurally unreachable section is visible before anyone
re-files its prediction (amendment 21).
