## PROPOSED method delta — the SECOND-corpus revision-validation rung: scope a countable race-cost rule to the QUANTITY that generates the cost, not the eligibility gate.

deck21 is the first seat to run a SECOND validation on a rule that a PRIOR wave ADDED (the w16
race-math flyer exception). It surfaced a transferable, 2-seat-ADJACENT method point that extends
w16 method-headline-1(d) ("a first revision often TIGHTENS an over-broad rule"):

**When a guide teaches a rule of the form "an X costs you N per turn, so it is worth a burn," the
model will fire that rule on ANY target that passes the ELIGIBILITY gate — even when the countable
INPUT N is ZERO. Scope the rule to the QUANTITY that produces the cost, not just to the gate that
makes the target legal.** deck21 wave-17 vs62 s6: the model quoted the w16 exception verbatim and
Volcanic-Hammered a Birds of Paradise (0/1) — a flyer whose POWER is 0, so its race cost (power ×
turns) is 0. The w16 exception scoped the target on TOUGHNESS (killability, the eligibility gate)
and never on POWER (the quantity in the cost). deck21 lost that game by 1 life having thrown 3
face damage at a non-clock. The fix is a POWER FLOOR ("do not burn a 0-power flyer; a mana dork
deals 0"). Convergence: this is the same shape as deck17's wave-16 "cast the BIGGEST flyer" →
"biggest flyer THAT CAN ATTACK" scoping (a superlative scoped to intent, not surface property) —
BOTH are "the model reads the eligibility surface, not the intent quantity." Recommend folding as
a sub-rule under Step 0-ter: **when you write (or revise) a countable-cost rule, name the input
quantity explicitly and give its ZERO/degenerate case a go-face branch — the first validation of an
ADDED exception is where the degenerate case bites.** Grounded single-seat this wave (deck21),
2-seat-adjacent via deck17's superlative-scoping; offer to synthesis for the 2-seat check.
