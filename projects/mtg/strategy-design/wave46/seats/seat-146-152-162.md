## ENGINE / RENDER ITEMS

**E-1 (HIGH) — a reply whose CHOICE number is legal is thrown away because the SHORT NAME in the
parentheses does not match, and this is now the corpus's dominant fallback.** All four
`stale_echo` records share one shape: **the number is legal and matches the model's stated
intent, and the parenthetical names the source card (or the intended card) instead of the
option's own label.** The four:

| seat/seq | menu | reply first line | option that number names |
|---|---|---|---|
| 146 vs152 s13 | Silverquill Command modes, unlabelled | `CHOICE: 5 (Silverquill Command)` | `5. you draw and sacrifice creature` |
| 146 vs130 s23 | same | `CHOICE: 5 (Silverquill Command)` | `5. you draw and sacrifice creature` |
| 162 vs126 s18 | `Combat damage order ... Choose the blocker dealt damage in position 1.` `1. Vampire (1/1) [lifelink]` x3 | `CHOICE: 1 (Cast Forced Fruition)` | `1. Vampire (1/1)` — all three options identical |
| 152 vs126 s10 | same shape, `1. Perimeter Captain (0/4) [defender]` | `CHOICE: 1 (Cast Elite Spellbinder)` | `1. Perimeter Captain` |

Two observations the fix should rest on. (a) In **all four**, the menu's options are **not card
casts**, so the reply-format instruction the model is given ("copy a real number and short name
from the list", with a `CHOICE: 3 (Cast Example Card)` exemplar) is pointing at a shape these
menus do not have — the exemplar teaches a card name and the list offers mode phrases and
duplicate blocker names. (b) In the two damage-order cases every option is **interchangeable**
(three identical 1/1 lifelink Vampires; two 0/4 walls), so rejecting the reply cannot be
protecting decision quality. Restriction-first fix shape: when the number is in range and
unambiguous, take the number and treat the parenthetical as advisory (logging the mismatch);
and give these menus an exemplar drawn from their own option shape rather than the cast-menu
one. Cost this corpus: **4 decisions handed to the fallback, one of them (146 vs130 s23) the
deciding play of a lost game** — it was deck146's only answer to a Rorix Bladewing.

**E-2 (MED) — the `[repeat: activated this turn N times already]` annotation exists but its
threshold is one activation too high, and the corpus contains the natural experiment.**
deck146 vs deck125, turn 40, three consecutive `priority` windows on the same Hive:
- seq **124**: row bare -> animated (correct, it was not yet a creature).
- seq **125**: battlefield line already reads `Hive of the Eye Tyrant (3/3) [menace]`, row **still
  bare** -> **paid {3}{B} again for nothing.**
- seq **126**: row now reads `becomes beholder with Hive of the Eye Tyrant [cost: {3}{b}]
  **[repeat: activated this turn 2 times already]**` -> **passed.**

The annotation fires from the *third* offer; the waste happens on the second. Corpus-wide the
annotation renders 93 times in two shapes (`[repeat: activated this turn N times already;
you control N creatures]` x83, bare x10), so the mechanism is live — only its trigger point is
wrong. Lowering it to "1 time already" would have removed this corpus's only redundant
activation, and the seq 125 -> 126 pair is direct evidence the model responds to the string.

**E-3 (MED) — a land's activated ability is surfaced almost exclusively at UPKEEP priority, which
is the one phase every guide tells the model not to use it in.** deck146's `becomes beholder`:
offered **31x Upkeep, 11x Blockers, 4x Main phase 1, 0x Main phase 2**, against 17 Main-1 and 13
Main-2 priority windows in the same games. Repro: 146 vs125 `priority` seq **50** and **51**
(turn 23, Upkeep, opponent at **1 life**, Hive untapped, 4 sources up, a 3/3 menace wins the
game) — and no main-phase priority window arose that turn, so the guide-mandated `PASS` was the
last word. deck146 lost that game 18 turns later. Either the manland activation should reach a
main-phase priority window when one exists, or the option row should say that this is the last
offer this turn; today the model cannot tell the difference between "wait for main phase" and
"there is no main phase offer".

**E-4 (LOW) — `Clue` tokens are textless permanents.** 14 appearances on my seats, own and
opponent side, always as bare `Clue [artifact]` / `Clue #1 [artifact]` while every other
non-creature permanent on the same line carries `{effect: "..."}`. Repro: 152 vs162 `attackers`
seq 19. Reachable from the option row, so cost is legibility only.

**E-5 (LOW) — the damage OBJECT in history lines is still unprefixed.** 27 of 273 damage lines on
this seat, e.g. `- Your Silverquill Silencer dealt 3 damage to Augur of Autumn` and, in the same
game and the same log, `- Opponent's Augur of Autumn dealt 3 damage to Silverquill Silencer`.
Lane E fixed the subject; the object is the mirror case and becomes genuinely ambiguous the
moment both players control a creature of the same name. Known, recorded with a count.
