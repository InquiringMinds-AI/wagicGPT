# Strategy-writing skill proposals from the deck146 seat (wave 54)

Only what this seat's evidence supports. Numbering continues from #208.

## S1 - A LITERAL THAT GREW A CAUSE CLAUSE IS A NEW LITERAL, EVEN THOUGH THE OLD ONE IS ITS PREFIX
The #188 three-number audit asks for old-string renders, new-string renders and takes. This wave
produced a shape it does not catch. Wave 53 rendered `Playing every land in this hand would not
cover any spell in it.` (10 renders). Wave 54 rendered that same sentence **0 times as a
standalone** and **11 times with an appended parenthetical** - and the parentheticals fall into
two families that call for OPPOSITE decisions (`(1 land is not enough for your cheapest spell at
mana value 2)` vs `(you have 3 lands; no spell in it is castable off {W}{U} alone)`). A guide
sentence keyed to the old literal still MATCHES, so a naive audit scores it live; but the
sentence is now underspecified, because one literal became two decisions. Three guides in this
seat quote that line.
**Proposal:** the audit's old-string column is scored on the FULL rendered string, not on
substring presence, and gains a fourth column - "families the new string splits into". Any
literal that gained a cause clause is re-keyed to the families or explicitly marked
family-agnostic. Applies to every lane that adds a "cause clause" (this wave: C, E).

## S2 - RECORD THE WINDOWS THE PILOT GOT RIGHT OFF A NEW RENDER CLAUSE, AND WRITE THE HALF IT DID NOT SAY
Four windows at `146v162` (s46/s49/s53/s55) were answered correctly off lane C's brand-new
`[DRAW PRICE: casting this draws YOU 7 cards ...- you would be at 1]` tail, with no guide sentence
about it, in a game the seat won at 4 life. A seat file that only records breaks would have
written nothing, and the next Forced Fruition seat would be rolling the same die.
**Proposal:** amend the seat-file shape - a decision class the pilot handled correctly ONLY from
a render clause that is new this corpus is a finding with a sentence owed, filed as "WHAT THIS
BOUGHT", and the sentence must state the SCOPE the pilot left unstated (here: the tax is on
spells, so attacks, land drops and loyalty abilities remain free). Evidence for the scope half:
the seat won that game by attacking under the same tax it correctly refused to pay for a spell.

## S3 - "MOST EXPENSIVE FIRST" IS A REFERENCE TO A NUMBER ON THE SCREEN, AND MUST SAY SO
deck146's cleanup order named its cards in order (Emeria's Call, Agadeem's Awakening, a second
planeswalker...). The named half PASSED 1/1. The unnamed tail - "then the priciest spell" - broke
2 of 7, both times sending a {2}{b} card while a {3}{b}{b} or {3}{b}{w} sat on the same numbered
list with its cost printed on the row.
**Proposal:** in a ranked-order instruction, any rung expressed as a superlative ("the priciest",
"the biggest", "your best") names the RENDERED FIELD it is a superlative over, or it is not a
rung. Named-card rungs verify; superlative rungs over an unnamed field do not.
