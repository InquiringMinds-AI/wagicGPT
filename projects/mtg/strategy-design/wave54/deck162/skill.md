# Strategy-writing skill proposals from the deck162 seat (wave 54)

## S7 - KEY A BRAKE TO THE ROW CLAUSE THE ENGINE PRINTS FOR THE THING BRAKED, NEVER TO A CATEGORY NAME
deck162's RULE 2 brakes "draw engines" - a category the guide then enumerates (Howling Mine,
Dictate, Puzzle Box, Forced Fruition, Master of the Feast). Under pressure the pilot widened the
category to "anything I could cast before my punisher is out" and answered `Cast nothing right
now` on **10 windows across two games** whose only spell was a Liliana's Caress or a Fog Bank -
cards that hand the opponent nothing. Six of those were the same two-row menu on turns 4 to 8 in
a game lost 0 to 38.
The engine had the discriminator on the row the whole time: every gift row prints
`{feeds: the opponent draws N extra card(s) per turn; converters on your battlefield: K ...}` and
non-gift rows print no such clause. Keying the brake to `{feeds:` makes it exact, makes the
correct brakes (two Forced Fruition declines at K of 0) still fire, and shrinks the rule.
**Proposal:** an exclusion rule states the RENDERED CLAUSE that identifies its members. An
enumerated category is acceptable only as a gloss AFTER the clause, never as the key - a
category is a set the pilot can join cards to; a row clause is not.

## S8 - A GATE THAT INVERTS ITS OWN RULE'S ARITHMETIC IS A BUG IN THE GUIDE, NOT A PREFERENCE
The same guide's RULE 2 counts Liliana's Caress as a converter (at opponent hand size 7+), and
its cast order gated Caress behind "a Howling Mine, Dictate or Puzzle Box is on your
battlefield". So the card that makes a later engine's K read 1 was ordered AFTER the engines it
enables. The pilot obeyed the order and never cast it.
**Proposal:** when a guide contains both a resource rule (what counts toward K) and an ordering
rule (what goes down first), a wave's checklist includes reading them against each other: any
card the resource rule counts as a PREREQUISITE cannot be gated behind the thing it is a
prerequisite for. This is cheap (it is a read, not a corpus) and it caught a six-window loss here.

## S9 - "HOLD MANA" IS A SPEED CLAIM, AND A GUIDE FOR A SORCERY-SPEED DECK MUST SAY SO ONCE
Three of the ten windows above were declined with an explicit "keep mana open for Underworld
Dreams / Fate Unraveler / Ob Nixilis" on the seat's OWN main phase. Every one of those cards is
sorcery speed; if any had been castable it would have been a row on that same menu. The pilot was
importing a correct habit (hold instants) into a deck that has none.
**Proposal:** any guide whose deck holds no instants or flash carries one sentence stating that
"hold mana" is not available to it, keyed to the ask ("if it were castable this window it would
be a row"). Guides for decks that DO hold instants keep the habit. This is a per-deck fact that
reads as a general one, which is exactly the kind that must be written down.
