# Deck-135 proposals: revisions to the strategy-writing skill (wave 5)

Format: QUOTE → EDIT → WHY. Ordered by leverage. Citations: run
matchups-20260713-145947, deck135 seat translogs. My deck is the loop's best evidence
this wave on RULE-CALIBRATION — how to write a fix that doesn't overshoot — because it
is the deck whose wave-4 loud rule (the attack floor) was audited head-on.

## P1. A fix can be OBEYED, correct, and non-overshooting — and STILL fail, because the leak moved to the ADJACENT untreated seam. Add "re-audit the WHOLE chain, not just the fixed rule and its inverse."

QUOTE (Step 0): "Audit last wave's #1 RULE specifically for OVERSHOOT. The louder a
fix, the more the executor over-applies it; a cured leak often returns INVERTED."

EDIT (add a sibling bullet): "Overshoot is only ONE of the two ways a fix moves the
leak. The other is DISPLACEMENT to the adjacent seam: a rule that works at seam X
exposes the bottleneck at seam X-1 (the step that FEEDS X). Before concluding a loud
rule overshot, check whether it is being obeyed AND is fine, and the losses now come
from a DIFFERENT decision kind entirely. Concretely: tally the fixed behavior's
success (deck135's attack floor: 13/13 attacker asks attacked, 0 suicide losses) AND
count how often the seam even had good material to work with (only 17 windows in 6
games offered a real creature) — if the seam is healthy but starved, the fix landed
and the new leak is upstream, not an overshoot of the fix."

WHY: wave-4 predicted deck135's attack floor would overshoot into suicide attacks. It
did NOT — the floor is obeyed and caused no suicide loss. The 1/6 came from the CAST
seam (durdle on value before deploying a body), which the attack rule can't reach. A
review that only looked for overshoot-of-the-loud-rule would have missed the real
lever and re-polished a working rule.

## P2. When a spotlight card stops appearing, DEMOTE it — an offered-count of 0 is evidence the hero rule is dead weight, distinct from "never drawn ≠ validated."

QUOTE (Step 2): "Never-drawn ≠ validated. Zero log evidence about a card is VARIANCE,
not proof. Keep its lines proportional."

EDIT (add the discriminator): "Distinguish TWO zero-offer cases. A card never DRAWN is
variance — keep its lines proportional. A card repeatedly in HAND but never castable
(a color/cost the manabase rarely meets) is a STANDING castability fact: its hero
treatment in the guide is dead weight, and the evidence is the pilot's own replies
declining it for a REAL affordability reason ('I lack white'), not the false-belief
delusion the hero rule was written to intercept. Demote the spotlight; the correct
fact is a deck-construction flag, not a louder cast exhortation."

WHY: deck135's Rule #2 hero-worshipped Diamond Faerie off wave-4's 22/0 refusal. This
wave it was offered 0 times and the one decline (vs110 seq53) was correct — it lacked
white for {2}{G}{U}{W}. The falsity-facts intercepted nothing; the real issue is a GWU
5-drop off a 2-Plains base (construction).

## P3. A ROLE-CHECK must name the SEAM it fires at. "Be the defender" that only reaches the blocker seam does not stabilize a deck whose real defensive act is casting bodies.

QUOTE (Step 1): "Role — as a per-turn ROLE CHECK keyed on BOARD-READABLE facts …
give each role its own numbered action line."

EDIT (append): "Bind each role's action line to the DECISION KIND that carries it. A
defender role that only changes blocking behavior does nothing for a deck whose
stabilization happens at the CAST seam (deploy blockers before you ramp/dig). If the
losing pattern is 'raced while durdling on setup,' the role flip must reorder the CAST
priority ('cast a body before any fetch/dig this turn'), not just add a blocking rule —
the pilot already blocks when asked; it never builds the board to block WITH."

WHY: deck135's defender role-check (attacked-twice / life≤14) fired the right condition
but only spoke to blocking. The pilot blocked correctly when asked (vs110 seq7, vs109
seq10/52) yet still got run over, because between blocks it spent turns fetching and
digging instead of casting the next blocker. The fix belonged at the cast seam.

## P4. Utility creatures need an explicit carve-out inside the attack floor, or the free-case rule taps them for nothing.

QUOTE (Step 5, act-floor): "'a creature attacks if ANY of: no untapped blocker /
toughness > biggest blocker's power / it trades up or draws a card' … a closed
exception for the empty choice."

EDIT (add): "Name any mana-dork / utility creature the deck runs as an exception INSIDE
the attack floor: the free case ('no blocker → attack with everyone') will otherwise
tap a mana creature for a 1-point chip and strip a blocker. State where it goes instead
('keep the dork for mana and blocking; attack with it only as your last body when the
chip matters')."

WHY: deck135's Boreal Druid (1/1, {T}: add {1}) got sent to attack under the free case
(vs133 seq21/37, vs109 seq61) — tapping a mana source and a potential blocker while
behind. Minor per instance but pure downside, and the floor endorses it by omission.
