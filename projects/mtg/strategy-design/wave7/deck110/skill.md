# Deck-110 wave-7 — proposals for the strategy-writing skill

Context: deck110 is the seat that OWNS the re-equip marker saga. Wave-5 designed the marker;
wave-6 found it shipped-but-INERT (wrong field) and made "verify a shipped representation fix
FIRED before crediting it" the skill's Step-0 headline. Wave-7 is that same marker's NEXT wave —
the fix landed and I verified it fired and is obeyed (no-op re-equip 50% -> 6%, 28/29 marked
offers declined). That closes a loop the skill currently only opens. My proposals complete it.

## P1 (PRIMARY, multi-wave completion) — a CONFIRMED-FIRED representation fix licenses DEMOTING the guide stopgap it replaced.

The skill's Step-0 "verify a shipped representation fix FIRED" bullet ends at verification. It has
no NEXT step for the wave that finds the fix DID fire. That next step is the stopgap lifecycle
applied to the guide: once the corpus confirms the representation fix fired AND is obeyed
(quantified: 28/29 here, no-op 50%->6%), the interim GUIDE defense that was covering for the
missing representation is now DOUBLE COVERAGE — pure attention tax — and must be DEMOTED per the
existing three-part demotion rule (quantify obedience -> keep load-bearing tokens verbatim ->
delete the scaffolding the stronger layer now carries). deck110 Rule #1 went from a 19-line
two-power PERCEPTION PROCEDURE + once-per-plating COUNT BRAKE to 10 lines: the wasted-{1} FACT, the
new marker string, the named RELEASE, the mana DESTINATION, and ONE demoted board-cue backup line.

Proposed edit: extend the Step-0 "verify a shipped representation fix FIRED" bullet with a closing
clause — "and when a prior-wave fix is CONFIRMED fired-and-obeyed this wave, DEMOTE the guide
stopgap it replaced (do not leave both the representation AND the full guide procedure running); the
guide keeps only the corrective fact + the marker string + the release + the destination, and one
demoted backup cue for the case the representation is ever absent." This is the natural terminus of
the shipped-but-inert / shipped-but-weak / shipped-and-obeyed trichotomy the wave-6 bullet already
names. Multi-wave evidence (same marker, wave 5->6->7); STRONGEST proposal.

## P2 (sharpening, single-seat) — the ONE counterexample to a validated representation fix: read its REPLY before re-opening the representation.

The single corpus-wide "took the marked option" was deck110's (vs131 s33). It LOOKS like the marker
being ignored — but the reply proves the pilot READ and UNDERSTOOD the marker, WANTED a different
legit equip (attach its 2nd Plating to another carrier), and TYPED THE WRONG INDEX. That is a
PLAN/CHOICE MISMATCH (intent collapse), an existing Step-2 class, NOT a representation weakness.
Proposed: a one-line addition to the "verify FIRED" bullet — "when a lone counterexample to a
confirmed-fired representation fix appears, read its REPLY: an intent-collapse at a correctly-
represented option (plan names option A, choice is the represented-as-wasted option B, head-int ==
choice) is a reply-protocol/model defect, not proof the representation is weak — do not re-open the
representation over it." This is a composition of two lines the skill already has ("read the reply
not the choice" + the PLAN/CHOICE MISMATCH class); offered as an explicit junction because the
temptation at a validation counterexample is to score it against the fix. Single-seat -> adopt as a
sharpening or hold to watch.

## P3 (watch, single-seat) — a per-instance "already attached" marker cannot catch MULTI-COPY churn.

The marker fires on "already attached to THIS target," so with N copies of a re-attachable permanent
the pilot can shuffle copies among carriers (move Plating-A off a carrier that holds Plating-B) and
every move is an unmarked state-change (vs131 T9: 6 equip decisions shuffling 2 Platings; only 1
marked). Low-value (total power unchanged) and it happened in a blowout, but it is a structural
BLIND SPOT of per-instance markers on decks running MULTIPLES. Route to engine-representation
(suppress the re-offer once every copy is attached to SOME carrier), never guide text. Watch;
promote only if a second multiples-of-an-equipment deck reproduces a costly version.
