# deck152 -> strategy-writing skill: proposals from wave-57 evidence only

## S5 - A GUIDE MUST NOT SAY WHAT THE RENDER REFUTES, EVEN WHEN THE CONCLUSION IS RIGHT

The trust doctrine says never teach doubt of the render. Its mirror needs saying too: **do not
teach a claim ABOUT the render that the corpus falsifies.** deck152's HOLD paragraph asserted that
answering `Cast nothing right now` under the declined note "re-opens the same list at the next
window and you will be answering it again inside the same turn". Measured: false in 66 of 66
windows - the board changed every time, so the next window was a new decision either way. The rule's
CONCLUSION (take HOLD once you have decided to pass) is still correct and still shipped; only its
stated mechanism was wrong, and a pilot who checks it against the situation block in front of it
learns the guide is unreliable about the surfaces it is asked to trust.

Proposal: the skill's verification pass should require every mechanism sentence in a guide
("because the engine will X", "this re-opens", "it re-asks") to be traceable to a counted corpus
fact, and should treat an unfalsifiable mechanism claim as a defect at the same rank as a wrong
number. A right conclusion is not a licence for a wrong reason at this tier - the reason is what
the model reasons WITH.

## S6 - COUNT WHAT AN ENGINE LINE SELECTS ON BEFORE BUILDING A RULE ON IT

`[you declined this exact list N times already this turn]` reads like a staleness signal and is a
menu-identity signal. Three decks in this pool key a rule on it. One diff (situation block vs the
previous window's) settled what it can and cannot support, and it took ten lines of python.

Proposal: when a guide rule keys on an engine literal, the seat file should record **what the
literal is computed from** and **how often it co-occurs with the state the rule cares about**, not
just how often it renders. The three-number literal audit already asks for renders / takes; a
fourth column - the rule-relevant co-occurrence - is where the invalid keys will show up.

## S7 - A DECK WHOSE ONLY OPEN LANE TURNS OUT TO BE A NULL IS A ROTATION CANDIDATE, AND THAT SHOULD BE SAYABLE

deck152's one live measurable rule was P6; adjudicating it honestly closed it rather than sharpened
it. What remains at this seat is a render ask (E-6, Pathway colours) and a matchup it drew no answer
to. The skill's rotation criteria are written around keys firing on correct play repeatedly; this is
a different exit - a key whose obedience had a measurable ceiling of zero - and it deserves to count.
