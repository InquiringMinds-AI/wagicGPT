## Ranked: what a human on the Vita would hit

1. **E14 — the forced-pass livelock breaker is dead in every window where the non-mana offered set is empty** (`AIPlayerBaka.cpp:6008-6060`). The player sees the AI opponent sit in declare-attackers / declare-blockers / cleanup / a pool-vs-potential-mana window forever, answering its own re-armed menu. Preconditions are the wave-71 shape (menu re-arm + answer every tick, identical state for 200 ticks) — rare, and the 630-game A/B saw none — but wave 83 recovered from it and this commit does not. Fix is one line: `stalled = sameState && (offered.empty() || sameRefusal)`, or feed the offered set from `hasAnyLegalAction`'s own predicate. Then E13's comment must stop calling the set a "recorded refusal".
2. **E6(b) — a draw that draws nothing and never decks.** With a reveal parked and the cards above it removed by anything other than a draw (mill, tutor, `bottomoflibrary`, shuffle), every draw step silently does nothing once the physical library is empty (`MTGGameZones.cpp:476-483`), and CR 704.5b never fires. The human sees "I did not draw this turn" or an opponent that cannot be decked. Needs a reveal that stays parked across those operations (a stalled or long-lived reveal), so behind the same rare gate as the round-2 defect it fixes.
3. **E6(a) — unstamped park sites are never the logical top** (`AllAbilities.cpp:1861` scry; `moveto(myreveal)` movers). Wave 83 drew them; 1c77d1b17 skips them and still suppresses deck-out on their account. Today's shipped exposure is the `aicode` mover lines (AI seat) because every shipped scry-draw is `delayed`; any future scry or reveal script hits it. Fix: stamp 0 at `:1861`, and treat `mRevealAboveCount < 0` as eligible at `MTGGameZones.cpp:446`.
4. **E8 human-seat prompt is still a mechanism argument.** The seat is now the right one, but nothing in this diff or its fixtures shows a human on the Vita being presented the sacrifice chooser (T5 drives P2 with `ai`; the only "presented" evidence is the `gEdictRechoiceArmed` stamp). Not new to this lane; carried from round 2.
5. **E2 caveat — a re-added-after-garbaged ability.** If any path calls `addToGame` on an element already in `garbage`, the swept-entry exemption leaves its second slot live and the sweep deletes it twice; the pre-W83 walk was immune. Not shown reachable; worth a `getIndexOf`-style guard in `moveToGarbage` if it ever is.

Items 1-3 are the ones that must be fixed before a human-facing Vita release; 4-5 are carry-overs / hardening.
