**ONE violation found and fixed — `deck130/strategy.txt`, the Starstorm X-menu clause.**
Before: `AND WHEN YOU DO CAST IT, THE X MENU IS UPSIDE DOWN. The "Announce the value of X" list
puts the LARGEST X on option 1 - the prompt says so - so option 1 is NOT X=1. ...`
After: `AND WHEN YOU DO CAST IT, READ THE X MENU'S OWN SENTENCE. The "Announce the value of X"
list states which option holds the largest X and lists them largest first: it says "option 1 is
the LARGEST X (X = N)", so option 1 is that N, not X=1. Decide your number first, then find the
row whose text reads "X = " followed by that number, and answer with THAT row's number. ...`
