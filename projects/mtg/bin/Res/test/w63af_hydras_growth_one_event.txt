#NAME: Hydra's Growth - the upkeep doubling is ONE counter event
#Oracle (Scryfall, 2026-09-05): "Enchant creature / When this Aura enters, put a +1/+1 counter on
#enchanted creature. / At the beginning of your upkeep, double the number of +1/+1 counters on
#enchanted creature."
#The granted upkeep ability looped `thisforeach(counter{1/1.1}) counter(1/1)`; now
#`counter(1/1.counter{1/1})` - one event of N (dot separator, see the Kalonian fixture).
#  aura enters: counter(1/1) -> Scales -> 2 counters on Grizzly Bears (4/4)
#  my upkeep:   N = 2 -> ONE event of 2, Scales -> +3 -> 5 counters -> 7/7
#RED on the old script: two events of 1, each Scales'd to 2 -> +4 -> 6 counters -> 8/8.
[INIT]
FIRSTMAIN
[PLAYER1]
inplay:Hardened Scales,Grizzly Bears
hand:Hydra's Growth
manapool:{2}{G}
[PLAYER2]
[DO]
Hydra's Growth
Grizzly Bears
assertpt 4/4 grizzly bears
goto end
goto upkeep
goto end
goto firstmain
assertpt 7/7 grizzly bears
[ASSERT]
