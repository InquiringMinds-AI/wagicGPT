# battlefield is empty. The engine gates aura cleanup on card->target being
# non-null (704.5m finding), so an aura whose target vanished can linger
# unattached in play. If Holy Strength is still on the battlefield (graveyard
# short one card), this fixture FAILS = PROVEN.

Grizzly Bears
