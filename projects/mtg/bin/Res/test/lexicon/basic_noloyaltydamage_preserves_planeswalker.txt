# power/toughness equal its loyalty (and carries noloyaltydamage). Jace Beleren
# enters with 3 loyalty, so under Spark Rupture he is a 3/3 creature: a Shock
# aimed at him resolves (goes to the graveyard, mana spent) but only marks 2
# damage, leaving the planeswalker in play with its loyalty intact.
#
# AUTHORING NOTE: Spark Rupture's ETB ("When Spark Rupture enters, draw a card")
# fires when the harness resolves it into play. Jace MUST be listed before Spark
# Rupture on the inplay line, otherwise Spark Rupture's ETB draw pulls Jace out
# of the still-populated setup library before the harness can place him, and he
# never enters (the original ordering made the cast look "blocked"). The single
# library card is what that ETB draw puts into hand.
