# exiles the split card after it resolves. Cast from the graveyard, Claim //
# Fame uses its Fame flashback cost {1}{R}; Fame's effect targets a creature
# on the battlefield (Grizzly Bears), and the card is exiled after resolving.
# Walking Corpse (Claim's would-be return target) stays in the graveyard,
# because from the graveyard only the aftermath (Fame) half is castable.

[PLAYER1]

[PLAYER2]
[DO]
Claim // Fame
Grizzly Bears
no
[ASSERT]
FIRSTMAIN
[PLAYER1]
inplay:Grizzly Bears
graveyard:Walking Corpse

[PLAYER2]
[END]
