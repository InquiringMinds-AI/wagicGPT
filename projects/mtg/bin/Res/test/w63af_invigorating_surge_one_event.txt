#NAME: Invigorating Surge - the doubling is ONE counter event
#Oracle (Scryfall, 2026-09-05): "Put a +1/+1 counter on target creature you control, then double
#the number of +1/+1 counters on that creature."
#The script doubled with `thisforeach(counter{1/1.1}) counter(1/1)` - N separate one-counter events,
#so every counter-added replacement fired N times. Now `counter(1/1.counter{1/1})` - ONE event of N.
#Discriminator = Hardened Scales ("that many plus one"). Grizzly Bears 2/2, 0 counters:
#  Surge's first counter(1/1)  -> one event of 1, Scales -> 2 counters (4/4)
#  the doubling (N = 2)        -> ONE event of 2, Scales -> +3 -> 5 counters -> 7/7
#RED on the old script: two events of 1, each Scales'd to 2 -> +4 -> 6 counters -> 8/8.
[INIT]
FIRSTMAIN
[PLAYER1]
inplay:Hardened Scales,Grizzly Bears
hand:Invigorating Surge
manapool:{2}{G}
[PLAYER2]
[DO]
Invigorating Surge
Grizzly Bears
assertpt 7/7 grizzly bears
[ASSERT]
FIRSTMAIN
[PLAYER1]
inplay:Hardened Scales,Grizzly Bears
graveyard:Invigorating Surge
[PLAYER2]
[END]
