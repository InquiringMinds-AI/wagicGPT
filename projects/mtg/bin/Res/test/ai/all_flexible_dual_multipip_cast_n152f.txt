# PRE-FIX this FAILS SILENTLY - no defer record, no ask, the cast simply never
# reaches the decision surface.  ManaEngine::deferFlexibleSource is asymmetric:
# its SELF test (sourceHasOtherNeeded) aggregates over EVERY ability whose
# source is the card under consideration, but its OTHER test (competesElsewhere)
# is evaluated per-ABILITY on whichever amp the loop happens to hold.  Reaching
# Scrubland#2 through its add{W} ability yields output {W} only, so
# amp->output->hasColor(BLACK) is false and Scrubland#2 is judged "dedicated to
# W" - otherUnusedCoversK becomes true.  Both halves true -> Scrubland#1 defers
# {W}.  By symmetry Scrubland#2 defers {W} too, and both defer {B}.  Nothing
# claims either pip and the payment walk returns empty.  This is exactly the
# mutual deferral the function's own comment claims to prevent; the guard fails
# because one half is source-scoped and the other is ability-scoped.
#
# LIVE WITNESS (deck152 vs116, seq17 t8 and identically at s19/23/25/28/30):
# five untapped sources reading "colours you can make: {g}{u}{w}" - four
# Deserted Beach ({T}:add{W} THEN {T}:add{U}) plus Barkchannel Pathway - with
# Teferi, Who Slows the Sunset {2}{U}{W} in hand.  "Cast Teferi" appears ZERO
# times in the entire game log.  Teferi's real name carries a comma, which the
# fixture zone parser splits on, so this fixture reproduces the SHAPE (all
# coloured pips on flexible duals only) with comma-free cards.
#
# POST-FIX competesElsewhere aggregates over ALL abilities of the candidate
# other-source, symmetric with the self test: Scrubland#2 is seen to also make
# the other still-needed colour, so it is NOT counted as a dedicated substitute,
# otherUnusedCoversK stays false, and Scrubland#1 takes the pip.  The change is
# strictly LESS deferral, so it cannot resurrect the over-offer shape - and the
# N-146a case it was written for is untouched, because a genuine MONO source has
