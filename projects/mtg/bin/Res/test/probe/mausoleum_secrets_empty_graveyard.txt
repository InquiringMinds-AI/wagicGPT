# N-136a repro (async driver): Mausoleum Secrets with an EMPTY graveyard.
# Its Undergrowth gate is target(<1>*[black;manacost<=type:creature:mygraveyard]
# |reveal) = a black card whose mana value <= the number of creature CARDS in the
# graveyard. With 0 creatures dead the only legal find is MV<=0 = NOTHING; the
# whole library is illegal for option one. Ritual of Soot is a black MV4 card -
# ineligible. The interactive-AI reveal seam offered the whole revealed library
# as PUT options (soft "[does NOT qualify]" tag only) and a model that picked the
# illegal Ritual had the pick silently bounced by the engine's canTarget - the
# tutor no-opped while the model believed it succeeded (deck136 wave-29 vs93).
#
# THE FIX (N-136a): the async seam reuses the SAME canTarget verdict as a hard
# ENFORCEMENT filter, and never asks when NOTHING is eligible - so an ineligible
# pick can never reach hand. This fixture pins that invariant: the stub is told
# to pick the illegal "Ritual of Soot"; it must NOT reach hand; the tutor auto-
# resolves to its shuffle branch (Ritual stays in the library).
# NOTE: the engine physically bounced the pick pre-fix too, so this is a
# REGRESSION GUARD on the end state (no illegal card to hand). The model-facing
# half (no phantom ask / no mis-plan) is validated live on the translog.
#
